## 实施记录

### 关键决策

- **UI 已在 M0/T2.0 完成脚手架（`design/app` 一对一）**，M4 主要是把 mock 数据换成真实数据流，因此严格复用现有 CSS Module 类名与 DOM 结构，避免视觉回归；仅按需扩展基元（`MethodBadge` 接受任意 HTTP 方法、`StatusBadge` 增 red/info 语气）。
- **查询与实时事件共用 `CaptureExchangeSummary` 单行结构**（在 core-protocol 定义并被 storage 复用），使历史分页与 live tail 渲染同一行类型，避免重复定义；为列表显示补齐 `secure`（scheme==='https'）与 `durationMs`（completedAt−startedAt）。
- **Inspector 详情按需拉取**：新增 `sessions.detail` 命令返回 `CaptureExchangeDetail`（摘要 + URL + 请求/响应头 + 正文引用元数据），正文字节再经 `body.read-range` 按 blob hash 分块读取；详情为每次选择的**组件本地状态**，body/header 均不进入 Zustand 全局，符合内存约束。
- **过滤模型**：当前 Capture 为临时代际内存镜像，关键字/method/status/host/type/duration 与协议分段（H1/H2/WS）均为**客户端视图过滤**——字段谓词 `matchesCoreFilter`（type 按响应 MIME 短标签 `typeLabel` 子串匹配，duration 保留 `durationMs ≥` 阈值的已完成 Exchange）与分段谓词 `matchesSegment` 共同派生可见列表；实时事件复用同一谓词裁剪，保持 live tail 与当前过滤一致。分页 `sessions.query` 仍保留可下推的 host/method/status/mime/search/protocol 维度供后续按需启用。
- **正文预览**：`BodyView` 文本类型（json/js/html/xml/text）用 CodeMirror（JSON 走 `@codemirror/lang-json` 高亮、只读、行包裹），非文本走 hex dump；单次预览上限 256KB，超出提示截断。

## 后续增强（2026-07-18：Capture 正确性与 Payload）

- **Recording 生命周期（暂停模型）**：Capture 数据管线常驻 App。Stop 只暂停记录（`proxy.setRecording{false}`），Mockttp listener 与系统代理保持运行、流量继续转发，保留当前 Core 全部记录；Start 恢复记录继续追加；系统代理只在退出/修复时恢复。
- **Clear 唯一删除**：Clear 调用 `storage.cleanup`，重置 event queue/cutoff 并删除 Core/Renderer Exchange/Body；Core 重启也释放临时数据。
- **稳定虚拟列表**：实时事件前插时按选中项 index delta 补偿 scrollTop，避免当前选中行跳动；切换 feature 保留选择、滚动位置、Inspector tab 与 splitter 宽度，新请求类型不支持原 tab 时才回退。
- **Payload 四模式**：`BodyView` 提供 Auto/Text/JSON/Hex。Auto 覆盖常见文本 MIME，并对未知 MIME 做严格 UTF-8 与控制字符探测；Text 允许用户查看含替换字符的非严格 UTF-8；JSON 尝试格式化且保留无效原文；Hex 随 Inspector 宽度动态调整每行字节数。
- **Inspector 数据准确性**：Cookies 解析所有重复的 `Cookie`/`Set-Cookie` header；Timing 使用 `headersSentTimestamp`/`responseSentTimestamp` 映射的真实 epoch；全局正文、header 与日志文本可选择复制。
- **布局与交互**：Capture topbar 使用对称三列轨道保持标题在 1280px/900px 居中且不与两侧控件重叠；按钮 hover/disabled 状态按 variant 收敛，disabled 控件不再显示 hover 反馈。
- **最终验证**：三 workspace typecheck 通过；Desktop 99、Proxy Core 193、Core Protocol 19，共 311 项单测通过；Windows package 与真实 packaged smoke 1/1 通过；生产依赖审计 0 漏洞。smoke 明确验证 Recording 期间 Clear 保留当前 Session 壳但 Exchange/Body 归零。
