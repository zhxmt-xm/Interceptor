## 实施

### Windows 发布

- Desktop 发布版本升至 `0.1.0`，固定 `appBundleId/appUserModelId=com.zhxmt.interceptor`、`asInvoker` 和稳定 MSI `UpgradeCode=29d9f14a-359a-4e75-9b75-0bd5b0b69aac`。
- Forge `maker-wix` 固定 x64、英语 1033、`defaultInstallMode=perUser`、无 auto-update coupling。`scripts/prepare-wix.ps1` 从官方/Range 镜像下载 WiX 3.14.1 portable，严格校验 41,297,555 bytes 与 SHA-256 `6AC824E1642D6F7277D0ED7EA09411A508F6116BA6FAE0AA5F2C7DAA2FF43D31`。
- `WINDOWS_CERTIFICATE_FILE/PASSWORD` 存在时，同一 `windowsSign` 配置签 app 目录与 MSI；无证书时明确产出 unsigned 开发 artifact，不伪报签名。
- `windows-installer-smoke.mjs` 用隔离 temp 安装目录构建 0.0.1/0.0.2 两版 MSI，验证 x64 metadata、静默 per-user 安装、真实 app CDP 启动、MajorUpgrade 删除旧版本、再次启动、ProductCode 静默卸载与零残留进程/目录。

### macOS 发布

- Forge 在 macOS 无身份时使用 `identity: '-'` ad-hoc 签名；`APPLE_SIGN_IDENTITY` 存在时使用 Developer ID。只有 identity + Apple ID app-specific password + Team ID 同时存在才启用 notarization，`@electron/notarize` 成功后自动 staple。
- `maker-dmg` 产出 ULFO DMG，`maker-zip` 同时产出后续更新需要的 ZIP。`macos-release-smoke.mjs` 在真实 macOS 上构建、验证 Swift helper 可执行/只读、deep strict codesign、DMG/ZIP；有 Developer ID 时跑 Gatekeeper，有公证凭据时跑 stapler validate。
- `.github/workflows/release-artifacts.yml` 使用不可变 action SHA，提供 Windows/macOS 原生 jobs；secret 只经 Actions 环境/临时 keychain 注入，不进仓库或日志。当前会话无 GitHub CLI、Developer ID 或 notarization secret，未伪造远程结果。

### Package 安全

- Packaged Renderer 从 `file://` 迁到固定 `interceptor://app/index.html`。协议在 app ready 前注册为 standard/secure/fetch/stream/code-cache，不启用 CSP bypass、Service Worker 或 CORS；handler 只接受 GET、固定 authority，路径必须留在 Renderer root。
- `GrantFileProtocolExtraPrivileges` 关闭。升级 `@electron/fuses` 2.1.3，并在 `packageAfterCopy`（平台签名前）以 `strictlyRequireAllFuses` 显式锁定 Electron 43 的 9 项 fuse，含 `WasmTrapHandlers`；未来 Electron 新增 fuse 会使 package 失败。
- Main/Preload production build 与 Proxy Core release build 默认不输出 source maps；Core 只有 `INTERCEPTOR_SOURCEMAPS=1` 时输出诊断 maps。
- `package-artifact-audit.mjs` 校验 app version、ASAR/Worker/helper 必需文件、禁止 `.map/.env/tests/source`、文件数/500 MiB 上限、九项 Fuse；配置 Windows 证书时要求所有 `.exe/.dll/.node` Authenticode `Valid`。
- 2026-07-20 窗口改为跨平台 `frame:false`，不显示 Windows 标题栏或 macOS traffic lights；Renderer 自有 54px 顶栏提供 drag region，button/input/menu 明确 `no-drag`。右上角自有 Minimize、Maximize/Restore、Close 通过三个窄 Preload/Main IPC 操作当前可信 BrowserWindow；Close 调 `app.quit()` 并复用既有 before-quit 系统代理恢复和 Core 清理。
- 系统 PNG/ICO/ICNS 与安装包窗口图标统一为固定 dark 主题渐变的 Lucide Zap；左上角 Sidebar Logo 保留随主题变化的同款 Zap。Lucide 许可证为 ISC，依赖许可证随包保留。

### 发布前验收

- Packaged smoke 增加真实 loopback origin → 显式 Proxy → Capture 持久化/详情，并执行 Composer、Rules validate、Breakpoints toggle、Diagnostics query；保留 Core kill/restart、Storage、Preload/CSP 和退出清理。
- Packaged smoke 使用临时 `--user-data-dir`，不读取或改写真实用户 profile/journal；检查 frameless 的 native chrome 高度，并通过 `closeApplication()` 验证真实 graceful quit。
- `ReleaseScreenshotMatrix` 在最终 exe 中遍历 Capture/Rules/Composer/Breakpoints/Diagnostics/Settings：light/dark 1280×800 共 12 张、dark 900×600 共 6 张、四语言状态共 24 张；每张检查页面无横/纵溢出。
- 既有 10 万行 Storage 稳定分页测试增加 10 秒门槛；当前 Windows 参考机完整插入+100 页读取约 1.82 秒。
