## 实现与决策

- `main/updates/github-release-update-service.ts`只访问固定`zhxmt-xm/Interceptor` latest endpoint；拒绝非stable SemVer、外域URL、跨tag路径、重复/缺失平台资产和显式错误架构。
- Windows只选`.msi`，macOS只选`.dmg`。单资产无架构标记时允许；有`x64/amd64/arm64`标记时必须匹配当前设备。
- 下载上限1 GiB，先校验Release声明size，流式写随机`.part`，逐块限制累计size并计算SHA-256；完整、同步后原子rename。失败移除临时文件。
- GitHub API的`digest`必须是`sha256:<64 hex>`且下载字节必须一致；tag CI发布后回读API确认三项资产摘要齐全。用户打开MSI/DMG后继续由平台验证签名。
- changelog取GitHub Release body，保留换行但始终作为React文本节点显示，限制16 KiB；不渲染远程HTML/Markdown。
- Preload只暴露`getUpdateStatus/checkForUpdates/downloadUpdate/openDownloadedUpdate/onUpdateStatusChange`。Renderer拿不到asset URL、下载目录或任意文件打开能力。
- 删除了`update-electron-app`、Squirrel maker、资源更新密钥/manifest/store/protocol override和相关脚本测试；packaged Renderer恢复为只读ASAR来源。
