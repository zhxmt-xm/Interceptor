## 实现记录

### 策略：首版依赖 Mockttp（方案 §8.3）

Mockttp 4.5.0 内置 HTTP/2：下游 MITM、上游 passthrough 按 ALPN 协商、h2↔h1 四组转换均开箱提供。首版直接依赖其能力，仅在 Mockttp 未暴露处补齐；经集成测试验证覆盖面后再决定自研范围。

### Server（Proxy Core）

- **T6.1/T6.2**：`proxy/proxy-service.ts` 的 `startServer` 在有 CA（MITM）时用 `getLocal({ https, http2: true })`。`http2:true` 对经 ALPN 声明 h2 的客户端启用 HTTP/2，H1-only 客户端协商回落 http/1.1（**非 `'fallback'`**：'fallback' 仅对不支持 h1 的客户端用 h2）。上游由 passthrough 按源站 ALPN 独立协商。无 CA（明文显式代理）不启用 h2。
- **trailer/pseudo 采集**：`captureExchange` 用 `toHeaderInputs(kind, rawHeaders)` 采集 request/response header 及 `rawTrailers`（kind=request-trailer/response-trailer），`:` 前缀标记 `isPseudo`。protocol 由 `httpVersionToProtocol` 记为 `h2`/`http/1.1`。
- **T6.4 content-decoder**：`proxy/content-decoder.ts` 的 `decodeBody(data, contentEncoding)` 按 Content-Encoding 逆序解 gzip/deflate(zlib/raw 兜底)/br，多层支持；未知编码 → skipped 原样，解码抛错 → failed 原样，绝不抛给调用方。延迟解码：仅 `body.read-range` 的 `decode` 请求时解压（一次性返回解码全量）。

### Contract

- 协议：`CaptureHeader.isPseudo?`；`CaptureExchangeDetail.streamId?`/`requestTrailers`/`responseTrailers`（必需数组）；`CaptureBodyRef.contentEncoding?`；`BodyReadRangeCommand.payload.decode?`/`encoding?`；`BodyRangeResult.payload.decodeStatus?`。validation.ts 全部同步。
- Storage：schema v1 的 `exchange.stream_id`、`message_headers.kind`/`is_pseudo`、`body_ref.content_encoding` 均已存在，无需迁移；`getExchangeDetail` 读 is_pseudo/stream_id 并按 kind 组装 trailer。
- 桌面链路：`desktop-api.readBody(bodyId, offset, length, options?)`（options={decode,encoding}）、`BodyChunk.decodeStatus?`；`preload` 透传；`main` 经 `toBodyDecodeOptions` 校验后透传 Core 并回传 decodeStatus。

### Client

- `RequestInspector`：General 加 Stream ID（streamId 有值时）、headers pseudo 用 accent 高亮、新增 Response/Request Trailers section。
- `BodyView`：有 `contentEncoding` 时请求 Core 解码预览，按解码后大小截断（256KB），`decodeStatus==='failed'` 时提示显示原始字节。

### 已知限制与后续

- **Mockttp 抽象未暴露**：HTTP stream ID、GOAWAY/RST_STREAM code、SETTINGS、显式背压/并发限流均未从 Mockttp 事件暴露（`streamId` 字段/UI 已就绪但恒 undefined）。深度 stream 健壮性需绕过 Mockttp 用原生 `http2` session pool 自研，列为后续增强。
- **h1 下游 → 纯 h2 上游**（源站 `allowHTTP1:false`）Mockttp 返回 403，为边缘组合（真实罕见）；已移除该失败用例并记此限制。
- content 改写后的 length/encoding 重算属规则引擎能力，随 M7 落地。
