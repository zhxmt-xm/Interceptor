提交：Updates 匿名检查与登录删除

报告创建：2026-09-24 10:39（UTC+08:00）；修订：2026-09-30

删除产品自身的GitHub登录和更新登录门槛。保留固定Release来源、用户手动下载与打开安装器；HTTP 404或请求失败显示失败，不要求账号、不改变仓库可见性。

UI 改动

  • Settings / Updates顶部：删除GitHub access整组，包括账号、设备码、登录/退出和仓库授权；原Version和Delivery内容自然上移。
  • 标题说明、Latest GitHub release、Update action：移除账号授权和私有频道文案，说明稳定版本与用户显式下载。
  • Release source：保留仓库名称，删除Private标记；不改变远端仓库可见性或个人Git/CI凭据。
  • 检查、下载、打开安装器继续使用原按钮和状态样式，不新增产品入口或测试专用分支。

Main 改动

  • Main / Updates：原先通过GitHubAuthService执行Device Flow、读取与刷新加密token；现在删除该服务、凭据类型及登录生命周期，GitHubReleaseUpdateService直接匿名请求固定仓库。
  • Main / Preload：删除账号查询、登录、授权页、退出与账号通知五个API及相关IPC；保留更新状态、检查、下载、打开和通知接口。
  • 错误与退出：HTTP非成功响应及网络请求失败进入failed；保留原Check重试。退出取消活动请求，迟到响应不能发布新Release或保留安装器；size、SHA-256、平台/架构、固定来源及原子落盘校验保持。
  • 影响边界：不读取个人Git/CI凭据、不公开仓库、不创建发布仓库、不改变固定来源；CA和Agent/MCP仍按原方式使用safeStorage。

工程与文档

  • 产品测试改为匿名请求、HTTP/网络失败、退出取消和更新按钮契约；删除OAuth专属测试与15语言登录词条。
  • 真实E2E增加Updates失败重试与同profile重启，Settings导航不再检查登录按钮；packaged smoke改为最新API白名单和真实匿名更新检查。
  • 正式设计直接使用已确认的无登录结构，删除候选开关和授权场景；更新14张浅深色基准及对应parity配置，架构与使用说明同步匿名契约。
