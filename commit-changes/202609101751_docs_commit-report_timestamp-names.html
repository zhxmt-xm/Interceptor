用固定时间格式命名改动说明

标题：docs: name change reports with minute timestamps

改动说明不再依赖提交后才知道的 commit ID。文件按分钟时间、类别、feature 和简述命名，报告与对应代码在同一次提交中保存。

工程与文档

位置：AGENTS.md → 提交与交付 → Commit 改动说明。

改前改后
用本次 commit ID 命名，只能在提交后生成，报告须由下一次提交收录。固定格式 YYYYMMDDHHmm_类别_feature_简述.html；文件名和正文都不要求本次 commit ID。
最新代码和它的说明不能一起入库。验证完成后生成 HTML，报告和本工作项代码同次提交。
报告文件名不便按时间排列。12 位本地时间精确到分钟；同名冲突加 _02，生成后不随 commit 时间改名。

文件名使用主要类别：UI 为 ui、Main 为 main、Core 为 core、Agent/MCP 为 agent-mcp、工程与文档为 docs。跨范围改动仍在报告正文分块。

保留简单约定：一个 commit 一份 HTML；CSS 和实际截图全部内嵌；不创建索引、图片目录或 JSON Schema。

已有文档报告按其时间改名为 202609101725_docs_commit-report_guidelines.html，报告文件的 SHA256 未因改名变化。它记录上一 commit 当时的约定；本报告记录后续的命名调整。
