统一命令入口接入 Release

在 npm start 中提供 Release，维护者不必离开统一菜单记忆另一条命令；原发版向导和直接命令继续保留。

工程与文档

顶层菜单与命令转发

位置：scripts/start.mjs 的顶层菜单、执行摘要和帮助输出。

改前

只提供 Development、Test、Build，并提示发版流程暂不接入；必须单独运行 npm run release。

改后

增加 Release，展示执行摘要和 GitHub CLI、源码 commit、发布确认提示；确认后转发到原 npm run release。

原因与影响：统一日常操作入口，不复制源码选择、版本、CI、tag、draft 或 Publish 逻辑；原命令及发版向导中的确认继续生效。菜单取消不执行命令，子命令失败继续按既有规则退出。
