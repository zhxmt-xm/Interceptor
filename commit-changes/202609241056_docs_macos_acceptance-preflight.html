位置改前改后原因与影响
MacosWorkflowHostSafetyOperations没有在App启动前检查GUI会话是否可用。通过CoreGraphics只读取得登录与锁屏状态，失败或锁屏时显式报错。不解锁桌面、不修改授权、不读取凭据；无效检查结果不静默放行。
LocalElectronApplicationDriver与packaged smokeApp可能先接管系统代理，之后因System Events看不到窗口而失败。每代macOS App和smoke均在创建profile或spawn前调用同一个前置检查。已锁屏时不启动App、不触发组件确认或代理接管；Windows原行为保持。
fixture及smoke说明、Handover窗口失败需要事后恢复，旧包的验证范围不包含最后的只读解析修正。说明解锁前置、当前产物源码身份和各层验证范围，区分前置拒绝与产品流程通过。恢复执行时使用当前包及原有workflow，不将旧smoke或锁屏拒绝当成新包验收完成。
packaged smoke 的 Main 日志macOS stdout/stderr连接runner的pipe；失败保留App而runner结束时，后续日志可能触发EPIPE。继承profile内0600日志文件，runner在spawn后关闭自己的文件句柄；失败保留profile，附加有界日志尾部，Windows仍用原pipe。保留App可以继续安全写日志，不给产品增加吞错分支，也不改变系统代理恢复保护。
Core重启与错误收尾断言macOS只等15秒发布新Core running，原断言错误可能被finally中的清理异常覆盖。按原生恢复30秒期限等待35秒，Windows仍15秒；原始错误和清理错误一起报告。与Core初始化等待代理恢复的真实顺序一致，不延长产品期限、不省略Recording或系统代理归属断言。
四个Tunnel parity场景详情标题与请求列表同文案，裸文本目标误量列表行。显式定位详情callout标题，比较相同文字范围。修正验收对象归属；产品、设计、截图基准和1px阈值均不变。
Handover与Settings证据索引当前产物验收重复挂靠其他item的未完成内容，Verification混入逐轮过程。已验收的当前产物退出未完成清单；Verification只保留结论短表，详细证据按范围归入Settings。区分本项验收与后续功能任务，保留历史失败和证据而不继续堆叠运行日志。
