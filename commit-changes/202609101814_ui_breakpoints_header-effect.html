断点 Header effect 下置，输入框保持等宽

提交标题：fix(ui): place breakpoint header effects below inputs

解决带 Rule effect 的行把输入框挤窄的问题。保留原输入框样式，将效果说明放到 value 输入框下方，紧贴并右对齐，不改变 Header 编辑或规则执行。

设计确认：2026-09-10 用户已查看前后预览并确认“就按这版就行”；采用 2px 间距、9px 字号、12px 行高的小字说明，未采用表格式或整列留白方案。

UI 改动

页面位置：Capture → HTTP 断点 → 右侧 Request Headers / Response Headers 编辑区，包含可编辑队首。

代码位置：BreakpointInspector.module.css 的 headerRow / headerEffectSlot / headerEffect；设计稿 HeaderFieldsEditor 和 HttpBreakpointDesign。正文、普通 Inspector、Core 与转发实现不变。

改前改后原因与影响
每行独立分配 effect 列，标签会挤窄本行 name/value 输入框。name/value 保持固定比例并在各行等宽；删除按钮按实际宽度占位。同一列边界对齐，消除有无 effect 的宽度跳变和删除列溢出。
效果为输入框右侧的 18px 高胶囊标签，字号 9.5px。效果位于 value 下方 2px，文字右对齐，9px 字号、12px 行高，无胶囊边框与底色。不占横向列。普通行仍 30px、行间距仍 6px；带 effect 的行增加 14px，总高 44px。
输入编辑、Add/Remove、Continue、Forward edited 按现有逻辑执行。事件、字段和命令参数不变；保留 set/append 文字与语义色。只改布局，不改变规则执行、Body 或 HTTP framing/encoding。

设计共享组件显式为 HTTP 使用下置样式；WebSocket 握手继续原 inline 设计。更新 22 张受影响基准，新增 4 张此前缺失的队首/菜单截图，其余 366 张 PNG 的 SHA256 不变。
