工程与文档：HTTPS 定位 workflow

位置
workflows/capture/macos-https-dialog-position.workflow.ts 与 Capture 规格。
改前
fresh profile 被当作没有 CA，定位流程要求 Generate 按钮可用，和普通 fixture 已检查的共享 CA 前提冲突。
改后
断言 Generate/Install 不存在，Start decrypting 可用但不点击；继续只读逐帧测量、截图和真实 Cancel。
原因与影响
profile 隔离不等于共享 CA 为空，不应为位置测量删除、生成或重新授信日常 CA。原 1px 居中阈值及主窗口位置约束保留。

工程与文档：每代 Page 的 TLS 提示 handler

位置
fixtures/ui/https-capture.ts、fixture README 与 Capture 规格。
改前
host 行触发后再用 locator 按 Enter；提示已关闭时，locator 会继续等待同名的替代按钮并超时。
改后
取得本次提示按钮的 ElementHandle，再发送真实 Enter，结束后释放。节点不存在或已 detach 表示旧提示消失；其他错误仍抛出。
原因与影响
不点击新的无关提示，不隐藏超时或页面错误。原操作继续进行 actionability 检查，新提示由同一 handler 处理；Windows 原 click 路径和每代 Page 注册范围不变。

工程与文档：原生 Save/Open driver

位置
fixtures/ui/macos-file-dialog.ts 与共享 fixture、Rules/Composer 规格。
改前
GoTo 输入后用 Return 提交；本机中文输入法在窗口关闭期间触发系统 Open/Save XPC 服务的 text-storage 越界，整个原生面板消失，没有产生目标文件。
改后
回读完整路径后，在 GoTo 原生建议表中精确匹配唯一目标名并发送真实双击；Save/Open、Cancel 通过原生按钮的位置执行真实单击。鼠标事件明确设置修饰键和点击计数，面板类型直接读取原生标识。
原因与影响
继续经过真实文件窗口和产品 Export/Import，不写 Accessibility 值、不修改返回值，不更改输入法或应用语言。只更换验收使用的正常鼠标操作，不宣称修复 macOS 系统服务；Windows driver 保持不变。

只有验收工具与规格变化，产品页面无像素改动。临时诊断代码和失败实现方案均已移除；原始失败、验证记录与后续处理统一在 Handover。
