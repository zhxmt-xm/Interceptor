Rules 标题无框编辑

2026-10-23 00:07 · UI / Rules

将规则详情标题恢复为可直接编辑的标题，不再在 hover 或 focus 时出现紧贴文字的表单框。

UI 改动

  • 位置：Rules → 选中规则 → 右侧详情标题栏，RuleEditor.module.css。
  • 改前：输入框保留透明边框和圆角，hover 显示边框，focus 显示强调色边框及底色；零内边距使细框贴着标题。
  • 改后：默认、hover、focus 均无边框、底色和阴影。点击区域高 28px、水平内边距为 0，保留 14px / 600 字体及标题栏 flex 居中。
  • 影响：不改重命名事件、规则身份、草稿、Save、Preload、Main 或 Core；不恢复旧的负 margin。长标题继续在输入框内部横向滚动。
  • 设计来源：RulesEditorHeader 使用真实 input 与 typed state，取代静态标题展示；规则选择更新标题，输入同步列表名称。设计规范与截图入口同步描述无框状态，不保留候选开关。

工程与文档改动

  • visual-parity/parity.config.mjs 增加四主题的默认、hover、focus、长标题、失焦场景，比较输入框本体、字体、边框、背景、滚动与相邻控件，不再只覆盖静态标题文字。
  • parity.mjs 支持显式读取原生表单控件的 stateKeys.value，并用 assertInputValue 核对场景输入。既有 compareText 语义与原始精度保持不变。
  • Rules Agent 查询场景明确清空审批状态，避免继承上一个 result 场景；不改 Agent 产品 UI，也不放宽比较规则。
